# Security policy

FIRA is an open-source **prototype running on synthetic data**. It has not had an external security review.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's *Report a vulnerability* (private security advisory) on this repository, or
contact the maintainer through the contact details on their GitHub profile. Include what you found, how to reproduce it, the
commit or version, and the impact you expect. You can expect an acknowledgement within 7 days and a status update within 30 days.
There is no bug bounty and no service-level commitment. Please test only against your own deployment with synthetic data.

Only the `main` branch is supported. The security controls, their tests and the known limitations are in
[docs/SECURITY.md](docs/SECURITY.md).
